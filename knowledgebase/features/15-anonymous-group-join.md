# Feature 15: Anonymous Group Join (Zero-Knowledge Proof)

> Walkthrough pending. Will be filled step-by-step in subsequent sessions.

## Concept summary

New members prove possession of a valid invite token via zero-knowledge proof without revealing their identity to existing members. The admin accepts the join anonymously; the new member's identity is shared only after acceptance (or stays pseudonymous if the group policy allows).

Useful for activist groups, whistleblower channels, and any context where the act of joining is itself sensitive.

## Why this is superior (preview)

- **Signal / WhatsApp / Matrix / SimpleX**: joining a group always reveals the joiner's identity to existing members from the first message onward.
- **LibertyChat**: structural option to join groups without doxxing oneself to other members.
